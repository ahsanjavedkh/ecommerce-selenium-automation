# Ecommerce Selenium Automation Project

## Project Description
This project automates an ecommerce flow using Selenium and Python with POM (Page Object Model).

## Features
- User Login
- Product Search
- Open Product
- Add Product to Cart

## Tech Stack
- Python
- Selenium
- POM Design Pattern
- VS Code
